# 划词智能翻译（Chrome 扩展）

选中文本后点击「译」，在原网页浮窗中查看简体中文译文。支持 ChatGPT 订阅网页授权和兼容 OpenAI 的 API；两种服务共用一个可编辑的翻译 Prompt。

Agent 接手请先读 [HANDOFF.md](HANDOFF.md)，其中记录当前版本、安装位置和验证边界。

## 安装（macOS）

1. 安装 Node.js 20 或更新版本。
2. 在 `chrome://extensions` 开启开发者模式，加载本项目根目录。
3. 在项目目录运行 `node bridge/install.js`，安装独立的订阅连接。
4. 重新加载扩展，打开设置，点击「登录 ChatGPT 订阅」，在网页完成授权。
5. 登录后自动读取模型。选择模型并保存，再刷新需要翻译的网页。

无需安装、启动或登录 Codex，也不读取它的配置、凭据或登录状态。

订阅连接安装到 `~/Library/Application Support/SmartTranslate/Subscription`，仅使用 Node.js。它负责接收网页授权回调、保存扩展自己的登录凭据，以及发送订阅请求。浏览器扩展存储中不保存订阅访问令牌。

安装脚本始终登记当前项目目录对应的扩展 ID。若使用了另一个固定 ID，可以传入 `node bridge/install.js <扩展ID>`，此 ID 会额外加入允许列表，不会覆盖当前目录的 ID。移动项目、更新连接代码或删除旧 Node.js 路径后，重新运行安装脚本并重新加载扩展。

## 登录与登出

- 只有点击「登录 ChatGPT 订阅」才会启动网页授权。完成授权后自动读取订阅模型；空模型列表会显示错误。
- 模型列表独占一行，选择后点击保存。已登录时重新打开设置会刷新列表。
- 「退出扩展登录」中止请求、清除扩展自己的凭据和翻译缓存；不会退出 ChatGPT 网页账号。Prompt、服务地址和其他翻译设置保留。
- 登录期间可点击退出取消。取消或失败的授权不会被保存，需要重新点击登录。
- 模型调用受账号订阅权限、额度和网络影响；不自动切换到 API 或其他模型。

## 翻译

- 拖动标题栏移动窗口，拖动右下角调节宽高；尺寸自动记住。右下角控件也支持方向键（10px）和 Shift＋方向键（40px）。点击底栏回转箭头恢复自动大小。长文独立滚动，操作栏保持可见；窗口内按 Esc 关闭。

- 浮窗顶部「A− / A+」调节译文字号（12–28px，每次 2px），点击中间字号恢复默认 14px。字号保存在当前浏览器扩展中，并同步到其他已打开网页的翻译浮窗。Chrome 与 Safari 版均支持。

- 译文随生成逐步显示，关闭浮窗、页面或发起新翻译会取消对应请求。
- 同模型、同 Prompt、同文本的结果短暂缓存，重复点击无需再次请求。
- 单一 Prompt 最多 4000 字符。默认输出简体中文，保留否定、条件、数字、单位和占位符；上下文仅用于消歧。
- 浮窗显示本次请求实测耗时，缓存命中单独标识。不同模型、网络和服务端负载会影响耗时。

## 兼容 API

选择「兼容 OpenAI 的 API」，填写 Base URL、API Key 和模型。可从 `/models` 拉取列表或手动填写模型 ID；翻译请求发送至 `/chat/completions`。

「清除 API Key」只清除扩展保存的密钥，不会撤销服务商后台的密钥。

## 故障排查

- 浏览器拒绝订阅连接：重新运行安装脚本，核对输出的扩展 ID 与扩展管理页一致，再重新加载扩展。
- 授权页面无法打开：确认订阅连接已安装；根据错误提示处理回调端口占用或网络问题后重试。
- 登录后无模型：检查订阅权限和网络，重新读取模型或重新授权。
- 修改代码后仍显示旧界面：重新加载扩展并刷新设置页；连接代码变化还需重新安装连接。
- 浏览器内部页、扩展商店、部分 PDF 或 iframe 页面不支持划词浮标。

相关检查：`node --test tests/install.test.cjs tests/bridge.test.cjs tests/translation.test.cjs`。使用模拟授权和接口，不读取真实凭据、不消耗模型额度。
